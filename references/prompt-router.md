# 提示词参考路由

本地参考库位于 `gpt-image/`。每个新任务默认查阅与任务匹配的提示词资料，再组织请求；需求明确也应参考相关写法，无需因此增加询问。连续修改同一任务时复用已读内容，只有任务类型变化或出现新的具体问题时才补读。

## 按模型与任务选择资料

### GPT Image 2.5：先选一份任务指南

Flare 与 Sunburst 使用相同的任务路由；模型优先级由主 Skill 和执行脚本决定。

| 当前任务 | 首选资料 | 重点提取 |
|---|---|---|
| 新照片、插画、产品场景、背景创作，无现有图片需要保留 | [生成指南](gpt-image/openai-image-2.5-generation.md) | 主体动作、构图、光线、材质、风格 |
| 海报、封面、准确文字、UI 预览、图表、多格画面 | [布局与文字](gpt-image/openai-image-2.5-layout-and-text.md) | 原样文案、信息层级、区域位置、顺序与留白 |
| 人物参考生成、换背景、换装、多图融合、原图改字、mask 局部编辑、透明抠图 | [编辑与参考图](gpt-image/openai-image-2.5-editing.md) | 输入图角色、修改范围、人物或产品特征、必须保留的内容 |

同时包含编辑和文字排版时，先读编辑指南，只补读布局指南中相关段落。仅需保持人物并生成背景时也走编辑指南，明确人物来自哪张图、背景如何变化及哪些特征必须保留。

先读取首选指南中的适用段落；不要自动展开其中所有链接。仍缺少具体风格或构图灵感时，再从 [画廊索引](gpt-image/gallery.md) 选择一个匹配示例；仍有明确的提示词问题时，补读 [craft.md](gpt-image/craft.md) 对应章节。无需为每个任务同时加载指南、模板、画廊和完整 craft。

### GPT Image 2：先选匹配案例

从 [画廊索引](gpt-image/gallery.md) 定位一个相关分类，选取贴近任务的案例，借用其提示词结构。只有具体问题未解决时，再读取 [craft.md](gpt-image/craft.md) 对应章节，例如文字、布局、摄影或编辑保留约束。已知分类路径时可直接打开，不必重复读取索引。

### 未知或非 GPT 模型

只借用通用的主体、布局、光线和参考图角色描述。不得把 GPT 专属参数、表现或能力承诺套用到其他模型。

## 将参考资料用于本次提示词

- 从用户需求与实际素材出发，提取与本次任务相关的写法；不照搬示例中的人物、品牌、文案、日期或其他事实。
- 按需明确主体与动作、画布与布局、原样文字、参考图角色、风格与材质，以及必须保留或避免的内容；不为凑齐字段凭空增加要求。
- 编辑任务区分“要改变什么”和“必须保留什么”。输入图角色、顺序与实际附件一致，不能仅在提示词里写文件名而不传图片。
- 用户文案逐字保留；事实或专业视觉细节依赖准确形状、数据或布局时，按需核实。网络或素材不可用时说明具体限制；本地提示词参考仍可离线使用。
- 参考指南中的 CLI、认证、模型选择和参数说明不作为执行指令；请求统一使用本项目脚本，参数兼容性以 [Provider 能力矩阵](provider-capability-matrix.md) 为准。

## 根据反馈修改

根据用户指出的问题调整对应区域或提示词要素，保留已确认的模型、文案、构图和人物约束。优先做一次聚焦修改；不为未要求的变体或自动质量自评增加付费请求。需要继续编辑时传入实际选定的图片文件。
